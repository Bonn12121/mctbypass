# Mystery Country Finder / Bypass

Interactive geography tool to pinpoint mystery countries from distance and direction clues in guessing games and Discord bots.

## Features
- **Clean Consumer UI**: Ultra-simple, focused interface inspired by modern tools.
- **Auto-Parsing**: Automatically extracts flags, distances (km), directions, and temperature indicators from pasted chat logs.
- **Great-Circle Precision**: Accurate Haversine distance and bearing calculation across 250+ countries.
- **Security Protected**: Cryptographically secured access passkey (SHA-256 encoded).
- **Interactive Map**: Built with OpenStreetMap & Leaflet with geodesic distance rings.
